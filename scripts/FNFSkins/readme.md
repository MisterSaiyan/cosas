# FNF Skins for Sonic and Amy

Small script that has model edits for sonic and amy that resembles boyfriend and girlfriend from fnf

## Amy (GF)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/MisterSaiyan/cosas/refs/heads/main/scripts/FNFSkins/AmyGF.lua"))()
```

## Sonic (BF)
