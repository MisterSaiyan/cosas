# Cosmetics Guide Example

Let’s say my Sonic uses front-studded shoes.<br>
Since the script doens't make the cosmetics invisible, they may clip through the remodel’s shoes.<br>
For that, we will use the recolorable presets given for the said shoe cosmetic.

<img width="477" height="577" alt="screenshot" src="https://github.com/user-attachments/assets/5f31761b-263d-43f5-ab9a-2d10416b7b3a" />

## 1. Equip the cosmetic

Let's make sure we have it equipped, always keep in mind your equipped stuff

<img width="1300" height="732" alt="screenshot2" src="https://github.com/user-attachments/assets/9b46c96c-9a2a-45ac-abc9-0ca317f53cc6" />

## 2. Select the Model Preset in Rayfield

Once we have it, let's do the thing<br>
Press “K” to open Rayfield, then click the option that matches your setup.

<img width="512" height="567" alt="screenshot3" src="https://github.com/user-attachments/assets/dec3b4b3-cc84-4110-a9b2-98033be862ed" />

## 3. Select Sonic

You can use the panel or you can wait for a round<br>
i would recommend for you to do this in ps before going to a public round<br>

Ta-da! Sonic looks consistent now :D<br>
(Although you'll need to go to Extras and recreate the palette yourself.)<br>
