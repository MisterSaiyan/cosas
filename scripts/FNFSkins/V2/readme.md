# FNF Skins for Sonic and Amy V2
# [V1](https://mistersaiyan.github.io/cosas/scripts/FNFSkins/)

Custom Skins that overrides Sonic and Amy with an custom designed boyfriend and girlfriend from fnf

Head Sync + Few Extras are toggleable by changing their value to true / false

Press R to Force Reload Sonic

Press T to Force Reload Amy

## Amy (GF)

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/MisterSaiyan/cosas/refs/heads/main/scripts/FNFSkins/AmyGFV2.lua"))()
```

## Sonic (BF) 

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/MisterSaiyan/cosas/refs/heads/main/scripts/FNFSkins/SonicBFV2.lua"))()
```
